# Popular-Movies-of-IMDb
**Project Learnings**
- Extracted raw IMDb movie dataset from Kaggle and performed data cleaning and manipulation using pandas
- Performed Exploratory Data Analysis (EDA) using pandas, matplotlib and seaborn libraries
- Analyzed movie rating distribution and identified the most popular movie languages and languages with the highest average ratings
- Analyzed the relationship between movie ratings and vote counts using sampling techniques to reduce overplotting and improve visualization
- Identified top-rated and most-voted movies by applying filters based on ratings and vote counts to derive meaningful insights
